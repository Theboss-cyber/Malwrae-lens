How It Works

Encryption

  • AES-256-GCM — industry standard authenticated encryption
  • PBKDF2 — 300,000 iterations of HMAC-SHA256 key derivation
  • Random salt + nonce — every file encrypts uniquely
  • Authentication tag — tampering is detected
  • Streaming — handles files of any size

Strong Password Tips

  • At least 12 characters
  • Mix upper, lower, numbers, symbols
  • Never reuse passwords
  • A lost password = unrecoverable data

Decryption

  • Only files encrypted by this tool ('.mlenc') are supported
  • Wrong passwords are detected and rejected
  • The GCM tag verifies integrity and authenticity
